## Frontend API Types

Frontend API types are generated from FastAPI's OpenAPI schema.

Generated file:

frontend/src/types/generated/api.d.ts

Do not edit this file manually.

To regenerate it:

pnpm generate:api


# type generation structure
FastAPI model
   ↓
OpenAPI schema
   ↓
generated/api.d.ts
   ↓
purpose-specific frontend type files
   ↓
React components

# manually added type:
for frontend only type, such as Step and Mode, we keep the manual added types

A useful rule is:

If FastAPI sends or receives it, generate it from OpenAPI. 

If React/Next.js invents it purely for UI state or transformed presentation data, keep it as a frontend type.
